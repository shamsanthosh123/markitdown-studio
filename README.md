## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/shamsanthosh123/markitdown-studio.git
```

### Navigate to the Project

```bash
cd markitdown-studio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:8080
```
